# 西寶功能說明（給群友看的版本）

## 連結預覽
- 貼連結就會自動回預覽，不用叫我。支援：Threads、X/Twitter、Instagram（貼文、Reels）、Reddit、Pixiv、Bluesky、Bilibili、Facebook、Pinterest、巴哈姆特、PTT。
- 影片會盡量下載後直接上傳成能在 Discord 播的影片；太大放不下就改貼能播的轉址連結。
- 多圖貼文會做成相簿（前 3 張，後面會寫還有幾張）；切成好幾張的長圖會拼回一張。
- X 的 R18 圖會打碼後上傳；Pixiv 的 R18 也走打碼卡。
- IG 限時動態沒有任何工具抓得到，我只會跟你說是誰的限動。
- 預覽抓不到時會一層層退到備用方案，全部失敗才會說「預覽載入失敗」。
- 不想要預覽：訊息裡任何地方寫 `nopreview`、`previewignore` 或 `fxignore`。
- 同一個頻道 60 秒內貼同一個連結只預覽一次。
- 預覽貼錯了：在我的訊息按 🗑️，或右鍵 → 應用程式 →「刪除西寶訊息」。能刪的人：貼連結的本人、有「管理訊息」權限的管理員。
- 我有「管理訊息」權限的話，會把原本那個（通常比較爛的）Discord 預覽收起來。

## 聊天（@西寶）
- @我就能聊天。附圖或 @我去回覆一則有圖的訊息，我看得到圖（額度用完的免費伺服器例外）。
- 我會記得同一個頻道最近幾輪對話，30 分鐘沒聊就清空；也會慢慢記住群友的長期印象。
- 用 `/memory show` 看我記得你什麼，`/memory forget-me` 叫我全部忘掉；`/memory guild` 看我對這個群的印象。管理員可以用 `/memory forget-user` 刪掉某個人的。
- 說「講個故事」「講一個關於貓的故事」，我會用群裡最近的真實對話當素材寫一篇短故事。
- `抽籤` 或 `運勢`：抽今日運勢。
- `/voice`：讓我用語音回答（原本的文字回覆不受影響）。
- 我會丟這個伺服器的貼圖和 emoji，也有自己的 emoji 庫。

## AI 方案與額度
- 三個方案，用 `/ai-tier` 看目前是哪個、切換要「管理伺服器」權限：
  - 入門：flash 模型，回 1~4 句，不讀群組前文。免費，整個伺服器共用每日額度。
  - 標準：pro 模型，2~8 句，會讀被 @ 前最近 15 則訊息。需要 DeepSeek API 金鑰。
  - 精細：pro 模型，3~15 句，讀群組前文，回得最詳細。需要 DeepSeek API 金鑰。
- 每日額度是整個伺服器一起算，台灣時間半夜 12 點重置。用完之後我還是會回，只是改用比較弱的備用模型，而且看不到圖。
- 想要無限額度或升級方案：管理員用 `/ai-key set` 設定自己的 DeepSeek API 金鑰（到 platform.deepseek.com 申請、儲值），再用 `/ai-tier` 選方案。`/ai-key status` 看狀態、`/ai-key remove` 移除。
- **金鑰只能用 `/ai-key set` 輸入**——指令參數別人看不到。絕對不要把金鑰直接貼在聊天裡；如果已經貼了，馬上刪訊息，並到 DeepSeek 後台把那把金鑰作廢換新。

## 排程（每天固定時間發）
- `/schedule add`：選頻道、時間（24 小時制，台灣時間）、任務類型。需要「管理伺服器」權限，每個伺服器最多 10 個。
- 任務類型：
  - 床邊故事：用當天群裡的對話寫一篇睡前故事。
  - 早安問候：早上跟大家打招呼。
  - 今日回顧：整理今天群裡聊了什麼、有哪些熱門訊息。
- `/schedule list` 看目前排了什麼，`/schedule remove` 用 ID 刪掉。

## 其他指令
- `/help`：完整說明（文字版）。
- `/debug-perms`：檢查我在這個頻道的權限夠不夠。
- `/servers`：我加入了幾個伺服器。

## 權限（管理員設定用）
- 需要：查看頻道、傳送訊息、讀取訊息歷史、嵌入連結、附加檔案（上傳影片用）。
- 建議加：管理訊息（收起原本的預覽）、使用外部表情符號與貼圖。
- 預覽沒出現時，先在那個頻道跑 `/debug-perms`。
