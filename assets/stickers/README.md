# 西寶自己的貼圖庫

放進這個資料夾的圖片，西寶在任何伺服器都能當貼圖丟出來。

Discord **沒有** application-owned sticker API（emoji 有，貼圖沒有），所以機器人自帶的
貼圖只能是「圖片附件」——好處是張數不受 Discord 的伺服器貼圖上限管，一張純圖片、
不帶文字的訊息在聊天室裡就是貼圖大小。

## 加一張貼圖

1. 把 `.png` / `.gif` / `.webp` / `.jpg` 丟進這個資料夾（單檔 ≤ `STICKER_LIBRARY_MAX_BYTES`，預設 2MB）。
2. 檔名就是貼圖名字（西寶寫 `[貼圖:檔名]` 來叫它）。想用中文名字或補說明就改 `index.json`。
3. 重啟西寶（資料夾只在啟動時掃一次）。

## `index.json`（選用）

只用來補「名字」跟「用途」。沒寫的檔案一樣會載入，名字取檔名。
用途寫清楚很重要——那是模型唯一能判斷「什麼時候該丟這張」的依據。

```json
[
  { "file": "wakeup.png", "name": "起床重睡", "meaning": "賴床/不想起床" },
  { "file": "no_pic.gif", "name": "沒圖", "meaning": "沒圖沒真相/催圖" }
]
```

## 伺服器自己的貼圖

不用放這裡。西寶會自動讀所在伺服器的貼圖（`guild.stickers`）並優先用那些——
同名時伺服器的贏，因為大家在丟的是那一張。
